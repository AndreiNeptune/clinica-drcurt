# Ghid de Contribuție

Vă mulțumim pentru interesul de a contribui la acest proiect!

## Cum poți contribui

1. **Raportarea Bug-urilor**: Deschide un "Issue" în GitHub descriind problema.
2. **Propuneri de Feature-uri**: Deschide un "Issue" pentru a discuta ideile noi.
3. **Pull Requests**:
   - Creează un branch nou (`feat/nume-feature` sau `fix/nume-bug`).
   - Respectă standardele de cod (ESLint/Prettier).
   - Scrie mesaje de commit clare (Conventional Commits).
   - Trimite un Pull Request către branch-ul `main`.

## Standarde de Cod

- Folosim TypeScript pentru tot codul nou.
- Componentele trebuie să fie funcționale și să folosească Hooks.
- Styling-ul se face exclusiv prin Tailwind CSS.
